# HalftoneLAB

HalftoneLAB turns images and 3D models into halftone, dither and pen-plotter-style vector art — in the browser at **[halftonelab.samolevsky.com](https://halftonelab.samolevsky.com)** or as a desktop app.

## Download

Get the latest version from **[Releases](https://github.com/Samolevsky/HalftoneLAB-Releases/releases/latest)**:

| Platform | File |
| --- | --- |
| macOS — Apple Silicon (M1 and later) | `HalftoneLAB-<version>-mac-arm64.dmg` |
| macOS — Intel | `HalftoneLAB-<version>-mac-intel.dmg` |
| Windows 10/11 (64-bit) | `HalftoneLAB-<version>-win-x64.exe` |

The macOS app is signed and notarized by Apple. The Windows installer isn't code-signed yet: if SmartScreen says "Windows protected your PC", choose **More info › Run anyway**.

## Updating

HalftoneLAB checks for updates shortly after it starts. You can also check any time with **HalftoneLAB › Check for Updates…** on macOS or **Help › Check for Updates…** on Windows. Updates download when you agree and install when you restart. Your settings and license are kept.

**Help › Release Notes** shows what changed in each version.

This repository only hosts installers and release notes. HalftoneLAB's source code is not public.
